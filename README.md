# Candidate Selection System

This is a simple JavaScript project which checks whether a candidate is selected or not based on their Coding Assessment and Technical Interview marks.

## How it works

First, the program checks the Coding Assessment marks. If the average is above the cutoff, it moves to the Technical Interview.

After clearing the Technical Interview, the program calculates the final average. If the final average is above the final cutoff, the candidate gets selected.

## Concepts Used

* JavaScript Promises
* `then()`
* `catch()`
* `resolve()`
* `reject()`
* `setTimeout()`
* Arrays
* `reduce()`

## File

* `assigment.js` - Contains the complete code.

## How to Run

Make sure Node.js is installed.

Run this command:

```bash id="j4w2ks"
node assigment.js
```

## Output

The program will display whether the candidate has cleared:

1. Coding Assessment
2. Technical Interview
3. Final Selection

If all stages are cleared, it will display a congratulation message.
